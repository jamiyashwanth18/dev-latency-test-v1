# Dev latency test - v1

A web app for a small team to manage leave. Employees can submit a leave request with start date, end date, type (annual, sick) and a reason. They see their requests and remaining annual balance (20 days per year). Managers see pending requests from their team and approve or reject them with a comment. Approved leave reduces the balance. A simple team calendar shows who is on leave each day. No external login: pick a user from a list.

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
ruff check .
ruff format .
```
